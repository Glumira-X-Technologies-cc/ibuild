📏 Tick Rule — What a tick means

Documents: Written pages compiled and filed as pages in that Book's Documents.md family.

Programming: Actual source, scripts and tests filed in Programming.md family, with test evidence.

Git: Committed, pushed, PR checks green, PR merged to main, parity checked, merge receipt filed.

Done but not filed = no tick. "Not applicable" is ticked only with a recorded accepted reason.
