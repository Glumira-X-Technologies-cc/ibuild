## Operational reconciliation

1. The ten-repository identity registry describes repositories, roots, remotes, floors, roles and authority. It is not the Van Clief filing hierarchy.
2. This law governs the GluMira 7.2 Library structure. Foyer subjects connect downward through functional Vaults, Rows, Cabinets, Books and Pages.
3. Documents, Programming and Git are Page layers for each topic. A missing layer is recorded as missing; it is never inferred complete.
4. One home per category. Other locations contain governed pointers or retained historical evidence.
5. Refile, never trim. When a Book or Page reaches its ceiling, open another. Never summarise source wording away.
6. Archive, never delete. Preserve original bytes, hashes, revision and source locator.
7. Prompts live in the tree. Change the source file and recreate generated output.
8. Git is the authoritative memory. Company Brain, Notion, Gemini and reports are derived views with source pointers.
9. No bulk filing move may use the old K01c path map. Regenerate a proposal-only map from fresh station main against this law, then verify it before bounded K01d parcels.
10. Subscription Tiers, the five GluMira surfaces, and Engines remain visibly unaccounted for until mapped into named current-law homes.
